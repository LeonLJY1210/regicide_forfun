00 准备：手机装好运行环境

你已装好 Termux。下面把"能跑游戏的服务器"装进手机。整套流程只做一次。

① 装 Node（游戏运行所需）

# 在 Termux 里逐行输入
pkg update
pkg install nodejs
pkg install git tmux # git 用于拉代码，tmux 用于后台保活
node -v                # 看到 v18+ 就成功

② 把游戏项目放进 Termux

方法 A 用我给你的 regicide-portable.zip（最简单）：先把 zip 下载/传到手机的"下载"文件夹，再进 Termux：

termux-setup-storage          # 首次会弹权限，允许
cp /storage/downloads/regicide-portable.zip $HOME/
cd $HOME
unzip regicide-portable.zip   # 解压出 regicide/ 文件夹
cd regicide
node server.js                # 启动！看到"本机访问 http://localhost:3000"即成功

方法 B 推到 GitHub 后克隆（适合之后要云端部署）：

git clone 你的仓库地址 regicide
cd regicide
npm install
node server.js

③ 让服务器在后台不掉

直接 node server.js 会在你关掉 Termux 时被杀掉。用 tmux 保活，并锁唤醒：

termux-wake-lock              # 防止手机休眠杀进程
tmux new -s reg               # 开一个后台窗口
node server.js
# 按 Ctrl+B 再按 D 脱离（服务器继续跑）
tmux attach -t reg            # 想回来看日志就这条
提示：只要 tmux 里的 node server.js 在跑，你的手机就是一台"游戏服务器"。下面所有模式都基于它。

01 单人游玩（全程本机，最省事）

单人模式完全在手机浏览器里算，不需要任何网络、不需要朋友。

  1. Termux 里确保 node server.js 在跑（tmux 里）。
  2. 手机自带浏览器（Chrome/Safari 都行）打开 http://localhost:3000（打不开就试 http://127.0.0.1:3000）。
  3. 首页点「单人游戏」→ 选难度 → 开玩。
这就是手机-only 单人最稳的路：不用电脑、不用外网、不耗流量，纯本地。就算在飞机上没信号也能玩。

02 局域网联机（同一 WiFi / 你的热点）

你和朋友要在同一个网络里。你当"主机"（Termux 跑着服务），朋友用浏览器连你的地址。

主机怎么看自己的联机地址

启动 node server.js 时终端会打印一行 局域网联机： http://192.168.x.x:3000，那就是给你的朋友用的地址。如果没看清，在 Termux 里查：

ip addr show wlan0 | grep inet     # 找 192.168.x.x 或 10.x.x.x

朋友怎么进

  1. 朋友手机连到和你相同的 WiFi / 你的热点。
  2. 朋友浏览器打开你给的 http://192.168.x.x:3000。
  3. 你这边点「创建房间」拿到 4 位房号，发给朋友；朋友点「加入房间」输房号即可。

分场景

🏠 家里 WiFi：最理想。你开 Termux 服务，全家连家里 WiFi，开你的 192.168.x.x:3000 即可。延迟通常 <5ms。注意：若路由器开了「AP 隔离 / 宾客网络」，设备间会互不通——用主网络、或关掉隔离即可。
🏫 学校校园网 WiFi：大概率连不通。学校 WiFi 几乎都开了 AP 隔离（防学生互攻），同一 WiFi 下设备之间被隔开。所以"校园网 + 局域网联机"基本失败，改用下面的公网或你的热点。
📱 你的手机热点：可行！让朋友连你的热点，他们开你的网关地址（通常是 192.168.43.1:3000，以 ip addr 显示为准）。注意：朋友会走你的蜂窝流量，人多动牌多会耗流量；适合两三个人就近玩。

03 公网联机（任意网络都能玩，强烈推荐在学校用）

公网 = 把服务器放到互联网上，所有人用网址进，不受校园网隔离、不受是否同一 WiFi 限制。这是在学校最稳的方案。

方案 A：免费 Node 云一键部署（最省心，全程手机可操作）

把 regicide/ 推到 GitHub，然后交给 Railway 或 Render（免费档）托管，它们会自动 npm install + npm start，给你一个公网网址。

# 手机上用 GitHub App / 浏览器，把 regicide 文件夹推成仓库即可
git add .
git commit -m "regicide"
git push

然后：

  • Railway：打开 railway.app → New Project → Deploy from GitHub repo → 选你的仓库 → 自动分配 xxx.up.railway.app。
  • Render：打开 render.com → New Web Service → 连 GitHub 仓库 → Build npm install、Start npm start → 得 xxx.onrender.com。（项目里已附 render.yaml / railway.json，会自动识别。）
部署好后，任何人（家里 WiFi / 学校 WiFi / 你的热点 / 纯蜂窝）只要在浏览器打开这个网址，就能创建/加入房间联机。你连 Termux 都不用开。单人也能直接开这个网址玩。
免费档注意：Render 免费版 15 分钟无访问会休眠，下次有人进要等约 30 秒"冷启动"；Railway hobby 档不休眠但有月度额度。无所谓，进一次就活了。

方案 B：手机 Termux + 隧道（进阶，不推荐新手）

在 Termux 本地跑服务，再用 Cloudflare Tunnel / ngrok 把本机暴露到公网。需要额外下载隧道程序（Termux 里装 cloudflared 较折腾），且依赖手机一直在线。不如方案 A 省事，仅作了解。

# 仅示意，新手跳过
pkg install cloudflared
cloudflared tunnel --url http://localhost:3000

04 场景速查表

你在哪 / 用什么单人和朋友联机怎么做
🏠 家里 WiFi✅ 本地即可✅ 局域网Termux 开服务，朋友开 192.168.x.x:3000
🏫 学校校园网 WiFi✅ 本地即可❌ 局域网通常被隔离用公网（云端部署网址）最稳
📱 学校用你手机热点✅ 本地即可✅ 热点局域网朋友连你热点，开网关 IP:3000（耗你流量）
🌐 任何网络 + 云端✅✅ 公网打开云端网址，创建/加入房间
✈️ 无信号✅ 纯本地❌只能单人（Termux 本地服务 + localhost）

05 排障与提醒

  • 朋友打不开我的 IP 地址 → 多半是 AP 隔离（学校/酒店常见）或连的不是同一 WiFi。改用公网方案。
  • 手机浏览器打不开 localhost:3000 → 试 127.0.0.1:3000；确认 Termux 里 node server.js 真在跑（tmux 里 tmux attach -t reg 看日志）。
  • 一关 Termux 游戏就断 → 没用 tmux/没 termux-wake-lock。按 00-③ 操作。
  • 校园网想联机又不想耗流量 → 公网云端部署是唯一干净解；你的热点会吃蜂窝流量。
  • 延迟高 → 同 WiFi 几毫秒；公网取决于服务器离你多远（Railway/Render 在境外可能 100~300ms，国内 Zeabur/旅鸟更近）。不影响回合制玩法。
一句话总结：单人永远本地跑（Termux + localhost，零流量零网络）；联机在家用局域网、在学校用公网云端网址最稳；学校热点能顶替局域网但吃流量。把项目推到 Railway/Render 一次，之后所有场景一个网址通吃。
