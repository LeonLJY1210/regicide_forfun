00先把服务跑起来

游戏是一个网页应用，需要先在你电脑（或服务器）上运行它，然后手机用浏览器打开。

cd regicide
./start.sh            # 默认 3000 端口
./start.sh 8080       # 也可以指定别的端口

启动成功后终端会打印地址：

本机访问：   http://localhost:3000
局域网联机： http://172.24.0.12:3000     ← 手机用这个
怎么看自己的局域网地址
如果终端没打印出来，可以另开一个终端查：
· macOS：ipconfig getifaddr en0
· Windows：ipconfig，找「IPv4 地址」，一般是 192.168.x.x
· Linux：hostname -I
也可以直接问浏览器：在同一个网络下的手机打开 http://<电脑IP>:3000/lan，会返回一个地址列表。
先自己试一下
在电脑浏览器打开 http://localhost:3000，能看见主菜单就说明服务正常。 手机要连的是同一个 WiFi，然后用终端里那个 192.168.x.x / 172.x.x.x 开头的地址。

01单人游玩：从开局到通关

官方单人规则

  • 手牌上限 8 张
  • 2 张小丑不进牌库，放在旁边当「重抽」用，每局各一次
  • 不能认输跳过——单人没有队友可以指望
  • 胜利评价：金（一次都没重抽）/ 银（重抽 1 次）/ 铜（重抽 2 次）

额外加的三档难度

  • 新手：手牌 +2，敌人生命 ×0.8
  • 标准：官方原版数值
  • 硬核：手牌 −1，敌人生命 ×1.2
在首页「开发者选项 → 核心数值 → 难度档位」里切换。

开局

  1. 手机浏览器打开地址，点 单人挑战。
  2. 直接进入牌桌。上方是当前敌人（血条 + 攻击 + 花色免疫提示），中间是已打出的牌，下方是你的手牌。
  3. 想先调难度/皮肤，回首页点 开发者选项 或 皮肤，改完再开局。

一个回合怎么走

  1. 出牌：点手牌选中，再点底部 出牌。合法组合有三种——单张、A + 任意另一张牌、同点数且总和 ≤ 10。选错了底部提示会变红告诉你「这个组合不合法」。
  2. 看花色效果：出牌瞬间会在敌人身上飘出数字，-12 是伤害、♥ +4 是回收、♦ 抽3 是抽牌、♠ 盾 +6 是护盾。
  3. 挨反击：没打死敌人就要挨打。系统会自动帮你选出浪费点数最少的弃牌组合，你确认底部按钮（挡下 10 点（已选 10））就行，也可以自己点牌改。
  4. 敌人被打死时，它会先做一个倒下的动画，然后下一个皇室登场——打死它的那一回合不用挨反击，可以接着打新的。

小丑重抽怎么用

底部 重抽 2 按钮只在你手牌 ≤ 2 张、或者挡不住反击时才真正有价值。它可以在出牌前或挡刀前使用：弃光全部手牌，重抽到 8 张。

别急着用
重抽用掉 1 次就从「金牌」掉到「银牌」。通常是眼看要死的时候才用——尤其是「手牌见底」和「挡不住这一刀」这两种情况。

提示 按钮

点了会用启发式算法算出一套推荐出牌并高亮（绿色描边），直接点「出牌」就能打。它会考虑护盾价值、能不能打死、留不留得住下一刀。注意它只是启发式建议，不是最优解。

02局域网联机（同一个 WiFi）

大家坐在一起、连同一个 WiFi，用这一种。延迟最低（通常 < 10ms）、零部署成本。

房主（开房间的人）

  1. 手机/电脑浏览器打开地址，点 创建房间。
  2. 大厅会显示 4 位房号（比如 XF33），下面还有一排局域网地址。
  3. 把局域网地址和房号都发给队友（点 复制房号 可以直接复制）。
  4. 等人齐（最多 4 人），点 开始游戏。设置可以在开始前用右上角 ⚙ 调。

队友（加入的人）

  1. 先用浏览器打开房主发的那个局域网地址（形如 http://192.168.1.5:3000）——这一步不能省，直接用自己的 localhost 是连不到别人的。
  2. 点 加入房间，填 4 位房号和名字。
  3. 进大厅等着，房主点开始你们就一起进牌桌。
最容易踩的坑
  • 队友必须打开房主的那个地址，而不是自己电脑上的 localhost。每个人的 localhost 都是自己。
  • 手机和电脑要在同一个 WiFi。有些路由器的「访客网络」会隔离设备，关掉它。
  • 公司/学校/酒店的网络常有AP 隔离，设备之间互相看不见。这种网络下局域网联机会失败，改用手机开热点让所有人连。
  • 电脑防火墙可能拦掉 3000 端口，允许一次即可。
想在同一台电脑上试
开两个浏览器标签页都打开 localhost:3000 就行——程序用 sessionStorage 区分身份，两个标签页会被识别成两个不同玩家。方便你自己一个人测联机流程。

03公网联机（异地，各自在家）

要让不在同一个网络的人连进来，需要让服务有一个公网可达的地址。三条路，按推荐顺序：

方案 A：部署到一台云服务器（最稳，推荐）

服务是纯 Node，无数据库、无状态依赖，扔到任意 VPS / 轻量应用服务器 / 容器都行。

# 在服务器上
npm install --production
PORT=3000 node server.js

# 想让它一直在后台跑
nohup node server.js --port 3000 > rg.log 2>&1 &

然后在云厂商的安全组 / 防火墙里放行 3000 端口。之后把 http://公网IP:3000 发给队友，输入房号就能连。

方案 B：内网穿透（不用买服务器）

服务仍跑在你自己电脑上，用穿透工具给它一个公网网址。注意：必须选支持 WebSocket 长连接的工具。

工具用法备注
Cloudflare Tunnelcloudflared tunnel --url http://localhost:3000免费，支持 WebSocket，会给你一个 *.trycloudflare.com 地址
ngrokngrok http 3000免费版够用，支持 WebSocket
frp / cpolar / 花生壳按各自文档配一条 TCP 或 HTTP 隧道国内访问速度通常更好
为什么不会断线
客户端每 4 秒发一次心跳，穿透工具的空闲超时（常见 60–100 秒）不会触发，连接能长期保持。

方案 C：路由器端口映射

在路由器里把外网 3000 端口映射到运行服务的电脑，然后队友访问 http://你的公网IP:3000。

大概率行不通
国内家宽（电信/联通/移动）通常没有真正的公网 IPv4，路由器 WAN 口拿到的是运营商内网地址（10.x / 100.64.x），映射了外面也访问不到。先确认路由器 WAN 口 IP 和你百度搜到的「IP」一致，不一致就别折腾这条，改用方案 A 或 B。

如果你用了反向代理（Nginx）

必须显式开启 WebSocket 升级，否则游戏能打开但一进房间就断：

location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 3600s;
    proxy_send_timeout 3600s;
}
不要放到纯静态托管上
GitHub Pages、Vercel 静态部署、Netlify、对象存储静态网站——全都用不了。联机依赖常驻的 WebSocket 服务进程，静态托管没有后端。

公网联机的稳定性

  • 游戏页右下角实时显示延迟：联机 38ms。绿色正常，红色说明 > 300ms。
  • 网络断了会自动重连（0.8 秒起，逐步退避，最多重试 8 次），回到原座位继续打，进度不丢。
  • 房主掉线会自动移交给还在线的玩家，房间不会散。
  • 顶栏 ≡ 打开战报页，底部有诊断信息：连接状态、延迟、种子、各牌堆数量。

05出问题了怎么办

现象排查
手机打不开网址确认同一 WiFi；确认用了局域网 IP 不是 localhost；电脑防火墙放行端口
提示「房间不存在」房号是 4 位大写字母数字；房主关掉页面后房间就没了
提示「该房间已经开局了」等下一局，或让房主用开发者选项里的「立即重开」
提示「房间已满」最多 4 人
能开网页但进房间就断公网部署时八成是反代没开 WebSocket 升级（见上一节 Nginx 配置）
延迟一直是红色换更近的服务器 / 换穿透节点；局域网的话检查是不是走了公网回环
队友看到「重连中…」等它自动重连；一直连不上就让房主重开一局
卡顿开发者选项把动画速度调到「快」或「关闭」

06规则速记

项目内容
目标合作击败 12 位皇室：4 个 J → 4 个 Q → 4 个 K
J / Q / K攻击 10 / 15 / 20，生命 20 / 30 / 40
手牌上限1 人 8 张、2 人 7 张、3 人 6 张、4 人 5 张
♥ 红心从弃牌堆回收等量牌，放回牌库底
♦ 方块全队顺时针共抽等量牌，满手的跳过
♣ 梅花本次伤害翻倍
♠ 黑桃敌人攻击力降低，可叠加、持续到该敌人被击败
花色免疫敌人免疫自己花色的特效（伤害照算）
精确击杀累计伤害正好等于生命 → 该皇室进牌库顶，日后当盟友（J10/Q15/K20）
小丑解除免疫 + 本回合不反击 + 由你指定下一位
失败条件任何人弃不出足够点数挡反击 → 全员失败
三条核心策略
1. 黑桃最值钱——护盾永久降攻，每张黑桃都在替全队省下之后每回合的弃牌。
2. 手里永远留够挡刀的点数——挡不住就是团灭，没有第二次机会。
3. 手牌是唯一资源，牌库见底比敌人血厚更致命，别用小牌硬凑伤害。
