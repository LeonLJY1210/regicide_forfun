# 弑君者 Regicide · 手机版

一副标准扑克牌就能玩的合作卡牌桌游。**手机浏览器打开即玩**，支持单人挑战、局域网/公网联机、四套皮肤、开局前可调的全套开发者选项。

> 规则来源：Badgers from Mars 出版的《Regicide》(2020, Paul Abrahams / Luke Badger / Andy Richdale)。

---

## 快速开始

```bash
cd regicide
./start.sh            # 默认 3000 端口；也可 ./start.sh 8080
```

启动后终端会打印两个地址：

```
本机访问：   http://localhost:3000
局域网联机： http://172.24.0.12:3000     ← 手机用这个
```

**手机与电脑连同一个 WiFi**，用手机浏览器打开「局域网联机」那个地址即可。

## 三种玩法

| 模式 | 说明 |
|---|---|
| **单人挑战** | 官方单人规则：8 张手牌、2 张小丑可重抽、金/银/铜胜利评价。额外提供新手/标准/硬核三档难度 |
| **创建房间** | 生成 4 位房号（如 `XF33`）。大厅里会显示局域网地址，发给队友即可入座，最多 4 人 |
| **加入房间** | 输入房号进房。同 WiFi 用局域网地址，异地则用部署后的公网地址 |

### 联机要点

- 服务器是**权威服务器**：客户端只发送「我想出这张牌」的意图，所有验证与结算在服务端完成，改前端改不了牌。
- 每 4 秒一次心跳，断线后按 0.8s → 6s 退避**自动重连**，回到原座位。
- 游戏页右下角显示实时延迟；战报页（顶栏 `≡`）可看连接状态与诊断信息。
- 房主掉线会自动移交给仍在线的玩家。
- 同一浏览器开多个标签页也能各自入座（身份用 sessionStorage 隔离）。

### 部署到公网（异地联机）

服务器是纯 Node，无数据库、无状态依赖，直接扔到任意容器/云主机即可：

```bash
npm install --production
PORT=3000 node server.js
```

对外暴露端口后，把 `http://<公网IP或域名>:3000` 发给队友，输入房号即可。

## 规则实现清单

- 城堡牌堆顺序：底部 K → 中 Q → 顶部 J，逐张翻开
- 三位皇室数值：J 攻击 10 / 生命 20，Q 15/30，K 20/40
- 三种合法出牌：单张 / A + 另一张牌 / 同点数组合且总和 ≤ 10
- 四花色能力：♥ 弃牌堆回收至牌库底、♦ 全队顺时针抽牌（满手跳过）、♣ 伤害翻倍、♠ 护盾降攻（可叠加）
- 结算顺序：红心 → 梅花 → 黑桃 → 方块；同时触发红心与方块时先红心
- **花色免疫**：敌人对应花色的特效被封（伤害照算）
- **精确击杀**：累计伤害正好等于生命 → 该皇室进入酒馆牌堆顶，之后可被抽到当盟友（J=10 / Q=15 / K=20）
- **小丑**：单独打出，解除免疫、免掉本回合反击、由你指定下一位行动的玩家
- **认输跳过**：不出牌直接承受反击；单人不能认输，其他人上回合全部认输时也不能
- **沟通限制**：联机不显示他人手牌（可在开发者选项里关掉这条限制）
- 胜负：击败最后一位国王即胜；任一人弃不出足够点数挡反击则全员失败

## 开发者选项

首页「开发者选项」进入，或在大厅/游戏顶栏点 ⚙。设置保存在浏览器本地，开局前调整即可。

**核心数值**
- 难度档位（新手 / 标准 / 硬核）
- 手牌上限、牌库小丑数（0 = 按人数自动）
- J / Q / K 各自的攻击力与生命值
- 梅花翻倍倍数、黑桃护盾是否跨回合叠加
- 花色免疫、精确击杀奖励、是否允许认输

**起始关卡 & 牌库**
- 从 J / Q / K 哪一档开始（可以直接跳到国王局练手）
- 是否把小丑洗进牌堆
- 随机种子（固定种子可复现同一副牌序）
- 公开酒馆牌库顺序

**调试透视 & 作弊**
- 公开所有玩家手牌（联机时服务器会真的下发全部手牌）
- 单人重抽无限制
- 自动高亮最优解
- 一键跳关 / 补满我的手牌 / 立即重开

**表现层 & 诊断**
- 动画速度（慢 / 正常 / 快 / 关闭）
- 音效、震动反馈
- 出牌确认方式（点确认键 / 再点一次卡牌）
- 显示延迟心跳、日志页诊断面板

> 联机时房主改动设置会同步给全房间；非房主改设置无效。

## 目录结构

```
regicide/
├── server.js              # Node HTTP + WebSocket 权威服务器（约 260 行）
├── start.sh               # 一键启动
├── package.json
├── public/
│   ├── index.html
│   ├── css/
│   │   ├── app.css        # 布局与交互
│   │   └── skins.css      # 四套皮肤变量
│   └── js/
│       ├── engine.js      # 规则引擎（前后端共用，含启发式 AI）
│       ├── ui.js          # DOM 渲染与动效
│       ├── net.js         # WebSocket 客户端（心跳 + 自动重连）
│       ├── devtools.js    # 开发者选项面板（数据驱动）
│       ├── audio.js       # WebAudio 合成音效（无外部资源）
│       └── main.js        # 应用主控
└── test/
    └── engine.test.mjs    # 引擎测试（含 600 局随机对局 + 480 局 AI 对局）
```

`engine.js` 同时被浏览器和 Node 引用，**单机与联机的规则表现完全一致**——不会出现"单机能玩的组合联机被拒"这类偏差。

## 小提示

这游戏比看上去难得多。AI 用启发式策略在标准难度下的通关率也不高——**输是常态**。三条最关键的策略：

1. **黑桃是最值钱的花色。** 护盾永久降低敌人攻击，每一张黑桃都在替全队省下之后每回合的弃牌。
2. **手里永远留够挡刀的点数。** 挡不住 = 直接团灭，没有第二次机会。
3. **别用小牌硬凑。** 手牌是唯一资源，牌库见底比敌人血厚更致命。
